jupyter-book checklist. version: 2.0.0a3
(to check in new versions, e.g. beta release)

features
- show / hide content for jupyter cells works
- Figure 6: <bold, greyed out> <caption + markdown, e.g. bold => white in dark mode>
- custom css styling
- same latex engine as vscode
- {cite} -> {cite:p}
- list-table 's are awesome
- label / references are very nice: easier UX compared to jb 1. 
    [](<relative_path>) or 
    [](#label) almost always works.

not supported / issues
- margin content
- render multi-axes matplotlib figures
- tqdm notebook (base tqdm works)
- dataframes look bad in dark mode
- hide source doesn't look as good as JB1
- font / highlighting in left sidebar doesn't look too good
- code background becomes transparent after around 120 cols
- github logo rendering when pasting github repo links
- latex equations look janky equations get cutoff vertically

* closing figures to make smaller notebooks => easier diff!
